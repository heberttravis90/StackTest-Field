# StackTest Pro

**StackTest Pro** is a mobile-first stack testing field application designed to simplify the testing workflow from pre-job planning through field testing and post-job review.

## 🚧 Current Status

**Version 0.4 — Beta / Active Development**

StackTest Pro is currently a working prototype. Calculations are being validated against known stack test data before the application is considered suitable for regulatory or commercial reliance.

## 📋 Workflow

**Pre-Job → Prelims → Field Testing → Results Comparison → Post-Job**

StackTest Pro includes two operating modes:

### 🔧 Field Mode

Designed for technicians actively performing a test.

Quick access to:

- Method 2
- Method 4
- Method 5
- Methods 6C / 7E / 10
- Method 25A
- Method 320 / FTIR
- RATA
- Tester vs. Client comparison
- Valid / Invalid run tracking
- Quick run saving

Field Mode keeps unnecessary screens out of the way while testing.

### 📊 Full Mode

Provides the complete project workflow:

- Pre-job planning
- Preliminary calculations
- Equipment checklist
- Field testing
- Multi-run management
- Valid / invalid run tracking
- Automatic valid-run averages
- Client / CEMS comparisons
- Permit comparisons
- Final job summary
- Post-job closeout

## 🧮 Preliminary Planning

StackTest Pro can use preliminary information from the client, previous testing, permits, or plant data to help plan the test.

Current tools include:

- Stack geometry
- Stack area
- Equivalent diameter
- Preliminary stack flow
- ACFM
- SCFM
- DSCFM
- Preliminary moisture
- Gas composition
- Molecular weight
- Method 5 sample planning
- Preliminary nozzle sizing
- Common nozzle comparison
- Analyzer planning
- NOx / Method 19 planning

## 🏭 Field Testing

### EPA Method 2

Field calculations include:

- Stack velocity
- ACFM
- SCFM
- DSCFM
- Stack temperature
- Stack pressure
- Differential pressure
- Moisture
- Molecular weight

### EPA Method 4

Moisture calculations include:

- Dry standard gas volume
- Condensate collected
- Silica gel gain
- Water vapor volume
- Bws

### EPA Method 5

Isokinetic and particulate calculations include:

- Nozzle diameter
- Sample volume
- Run time
- Stack conditions
- Isokinetic percentage
- Part
