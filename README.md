# StackTest Field

A mobile-first field application designed to help stack-testing professionals perform calculations, manage QA checks, record test-run data, and generate field results more efficiently.

## Live Application

https://stack-test-field.vercel.app

## About the Project

StackTest Field was created from real-world experience in environmental stack testing.

The goal is to reduce repetitive field calculations, organize test data, and give technicians and project managers a practical tool that can be used directly from a phone or computer.

The application is designed around actual stack-testing workflows rather than being a generic calculator.

## Features

- Stack-testing field calculations
- EPA Method 2 flow calculations
- Wet and dry standard flow rates
- DSCFH and SCFH calculations
- Test-run data management
- QA and equipment checks
- Mobile-friendly interface
- Installable Progressive Web App (PWA)
- Offline functionality
- Field reporting tools

## Technologies

- HTML5
- CSS3
- JavaScript
- Progressive Web App (PWA)
- Service Worker
- Web App Manifest
- Git / GitHub
- Vercel deployment

## Why I Built It

I work in environmental stack testing and wanted to build software that addresses problems I encounter in the field.

This project combines my industry experience with software development by turning real testing workflows and calculations into a usable application.

Instead of building a tutorial project, I wanted to create something that solves an actual problem and can continue to grow as I develop my programming skills.

## Development

StackTest Field is actively being developed. Future versions will expand calculations, reporting capabilities, QA tools, and field workflow features.
