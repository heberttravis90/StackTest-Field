StackTest Pro v0.34 RC1 — Saved Jobs Library

Built from v0.33 RC3 Traverse Display Fix.

NEW
- Added Saved Jobs to the side menu.
- Current jobs are automatically stored in a local job library on the device.
- Saved Jobs shows Job ID/name, client/facility/unit, test date, and last-saved time.
- Saved jobs can be Opened, Duplicated, Exported, or Deleted.
- Starting a New Job preserves the current job in Saved Jobs instead of erasing it.
- Existing v0.33 current-job data is automatically migrated into Saved Jobs after this version loads.
- Imported JSON backups are added to Saved Jobs.
- Export Full Backup remains available for off-device backup.

PRESERVED
- v0.33 RC3 readable Method 1 traverse/probe-mark display fix.
- Existing method-driven workflow, field testing, results, closeout, theme, and settings.

IMPORTANT
Saved Jobs uses browser/app localStorage on this device. Clearing site/app storage can erase locally saved jobs. Use Export for important off-device backups.
