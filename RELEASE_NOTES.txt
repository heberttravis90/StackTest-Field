StackTest Pro v0.53 RC1 — Method 7E RM Bias Correction

NEW IN v0.53 RC1
- Added an optional Method 7E reference-method correction workflow inside Part 75 RATA.
- Supports zero-gas Equation 7E-5b and non-zero-low-gas Equation 7E-5a.
- Stores raw RM averages, shared certified/direct calibration values, and per-run pre/post low and upscale responses.
- Calculates and displays the corrected RM value for each run.
- Screens pre/post system bias and low/upscale drift using Method 7E limits and the 0.5 ppm alternatives.
- Uses only the corrected RM values in RATA statistics when correction mode is enabled.
- Keeps the reference-method correction separate from the Part 75 CEMS statistical bias test and BAF.
- Preserves manual corrected-RM entry for existing jobs and workflows.
- Updated About / Legal and refreshed the offline cache.
